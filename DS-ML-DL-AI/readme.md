- [Z score](https://youtu.be/LZzq1zSL1bs?si=p1eO8SJDPIGNpEJ9&t=5862) - How many standard deviation away a datapoint is from mean, refer above image. Z score = (every data point - average)/standard deviation. [Modified Z score](https://youtu.be/m7KWxX23zCU?si=s0MrBjgX6XgaJyzf) - Modified Z score = 0.6745 *(every data point - median)/MAD where if modified_z_score > 3.5 may consider as outliers.
- Using percentile method with values in Inter Quartile Range along with lower and upper bound values and remaining as outliers it's possible to remove outliers.

- RNN for short term memory , LSTM supports both short and long term memory with four gates (3 I/P ,1 O/P),GRU are famous architectures. Also using these archs also implement 1 to 1,1 to many,many to 1, many to many sequences.
- Above mentioned sequence have limitation of no. of inputs always = no. of outputs, to overcome it they introduced encoders and decoders that encodes input pass it through context vector to decoders in paper "Sequence to sequence learning". 
- In classical mapping the input and output will mismatch so to overcome it use encoder-decoder arch but it too cannot handle longer sentence so they introduced Attention concept in paper "Neural Macine Translation with Attention"
- Using "Attention" concept google published paper "Attention is all you need" describes use of encoders and decoders without internal archs like RNN,LSTM or GRU
- "Universal language model fine-tuning for text classification" paper tells how to use LLM to our task.
